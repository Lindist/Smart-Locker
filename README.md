# 📦 Intelligent Parcel Locker System (ระบบตู้ไปรษณีย์อัจฉริยะ)
ระบบตู้ล็อกเกอร์พัสดุอัจฉริยะแบบ **4 ช่องตู้ (4 Lockers)** ทำงานผ่านเว็บ Full Stack (Next.js + TypeScript + Tailwind CSS) รองรับการแบ่งสิทธิ์ผู้ใช้งานเป็น **3 สิทธิ์หลัก (ผู้รับ, ผู้ส่ง, และ Admin)**

---

## 👥 ระบบสิทธิ์ผู้ใช้งาน (3-Tier Roles)

ระบบมีแถบด้านบน (User & Role Switcher) ที่สามารถคลิกสลับผู้ใช้งานเพื่อทดสอบการทำงานของแต่ละสิทธิ์ได้อย่างอิสระ:

### 1. 👤 สิทธิ์ผู้รับ (Recipient)
* **แสดงรายการพัสดุที่รอรับ:** แสดงข้อมูลพัสดุที่ส่งมาถึงผู้รับคนนั้นๆ พร้อมระบุว่าอยู่ในตู้หมายเลขใด (เช่น ตู้ที่ 2)
* **แสดง QR Code:** มี QR Code คมชัดขนาดใหญ่ สำหรับใช้สแกนเปิดตู้
* **แสดงรหัส PIN 6 หลัก:** แสดงรหัสตัวเลขขนาดใหญ่ (เช่น `584912`) พร้อมปุ่มคัดลอกรหัส
* **ปลดล็อกตู้:**
  * กดปุ่ม *"ปลดล็อกตู้ทันที"* จากการ์ดพัสดุของตนเอง
  * หรือกรอกรหัส PIN / Token ในช่องกรอกรหัสเพื่อสั่งปลดล็อกตู้

---

### 2. 🚚 สิทธิ์ผู้ส่ง (Sender / Courier)
* **แสดงรายการตู้ทั้งหมด 4 ตู้:**
  * ตู้ที่ 1, ตู้ที่ 2, ตู้ที่ 3, และ ตู้ที่ 4
  * แสดงสถานะชัดเจน: 🟢 ว่าง (AVAILABLE) / 🔴 มีพัสดุ (OCCUPIED)
* **ขั้นตอนการส่งของ (Locker Deposit Flow):**
  1. ผู้ส่งแตะเลือก **ตู้ที่ว่าง** -> ระบบจะ **สั่งปลดล็อกตู้นั้นทันที** (สถานะประตูจะเปิดออก)
  2. ผู้ส่งนำพัสดุใส่ในตู้ แล้วดันปิดประตูตู้
  3. เลือกผู้รับจากรายชื่อ (สมชาย ห้อง 101, สมศรี ห้อง 205 ฯลฯ) และระบุหมายเลขพัสดุ
  4. กดยืนยันส่งของเรียบร้อย -> ตู้เปลี่ยนเป็นสถานะ **"มีพัสดุ (OCCUPIED)"** พร้อมสร้างรหัส PIN 6 หลักและ QR Code ให้ผู้รับคนนั้นทันที

---

### 3. 🛡️ สิทธิ์ Admin (ผู้ดูแลระบบ)
* **สิทธิ์ปลดล็อกตู้ทุกตู้ (Master Locker Unlock):**
  * มีแผงควบคุมตู้ทั้ง 4 ตู้ สามารถกดปุ่ม *"สั่งปลดล็อกตู้นี้ (Master Unlock)"* ได้ทุกตู้ในระบบ
  * สั่งปิดประตู หรือ สั่งรีเซ็ตตู้ให้กลับเป็นว่าง (AVAILABLE)
* **กำหนดสิทธิ์ผู้ใช้งาน (Role Assignment):**
  * มี Dropdown ให้ Admin เปลี่ยนสิทธิ์ของ User แต่ละคน (ผู้รับ / ผู้ส่ง / Admin) ได้เฉพาะในหน้านี้
* **จัดการข้อมูลผู้ใช้ทั้งหมด (User CRUD):**
  * ดูรายชื่อผู้ใช้ทั้งหมดในระบบ
  * เพิ่มผู้ใช้งานใหม่ (+ Add User)
  * แก้ไขข้อมูลผู้ใช้ (ชื่อ, Username, ห้อง, เบอร์โทร)
  * ลบผู้ใช้งานที่ไม่ต้องการออก
* **จัดการข้อมูลพัสดุทั้งหมด (Parcel CRUD):**
  * ดูรายการพัสดุทั้งหมดในระบบ (หมายเลขพัสดุ, ตู้ที่เก็บ, ผู้รับ, ผู้ส่ง, PIN, สถานะ)
  * แก้ไขข้อมูลพัสดุ (หมายเลขพัสดุ, รหัส PIN, สถานะ PENDING / PICKED_UP)
  * ลบพัสดุ (หากลบพัสดุที่อยู่ในตู้ ตู้จะคืนสถานะเป็นว่างให้โดยอัตโนมัติ)

## 🚀 วิธีเปิดใช้งานโปรเจกต์ในเครื่อง (Local Development)

เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรันคำสั่ง:

```bash
# รันเซิร์ฟเวอร์
npm run dev
```

เปิด Web Browser ไปที่: **[http://localhost:3000](http://localhost:3000)**

## 🛠️ โครงสร้าง API Endpoints

* `GET/POST /api/auth/current` - ตรวจสอบผู้ใช้ปัจจุบัน และสลับผู้ใช้สำหรับทดสอบสิทธิ์
* `GET/POST /api/lockers` - ตรวจสอบสถานะ 4 ตู้, สั่งเปิดตู้ฝากของ, ปลดล็อกรับของ, Admin Master Unlock
* `GET/POST/PUT/DELETE /api/users` - จัดการข้อมูลผู้ใช้และกำหนดสิทธิ์ (CRUD & Role Assignment)
* `GET/PUT/DELETE /api/parcels` - จัดการข้อมูลพัสดุในระบบ (CRUD Parcels)
